Run the scan from the site, from the HTTP API, or from any agent that speaks MCP.

Run a scan

Paste a docs or website URL on the home page. The report opens when the scan finishes, in about 90 seconds. Reports are unlisted: anyone with the link can read one, and nothing links to it.

HTTP API

Start a scan

curl -X POST https://devradar.rexstjohn.com/api/scan \
  -H 'content-type: application/json' \
  -d '{"url": "docs.example.com"}'
202Started. Returns token and reportUrl.
200This domain was scanned in the last 24 hours. Returns that report, with reused: true.
409The domain's daily request budget is used up. Returns an error naming the reset time, and the last report if there is one.
429This address started 8 scans in the last hour.
400The URL cannot be scanned.

Read a report

curl https://devradar.rexstjohn.com/api/report/TOKEN

Returns the report as JSON. status is running until the scan finishes, then done, so poll every few seconds. The main fields:

headlineThe one-line summary, once the scan is done.
findingsOne entry per check: probe, result (pass, fail, info or unknown), severity, headline, the url it looked at, and the evidence behind it.
competitorsThe competitors the scan found, with their docs URLs.
bannerThe most serious problem, if there is one.
ceilingHitTrue when the 150-second limit cut the scan short. Checks it did not reach come back as unknown.

MCP server

The DevRadar MCP server lets Claude Code, Cursor, Codex and other agents run the scan and read the report. It needs Node 20 or later and no API key. Add it to your agent's MCP settings:

{
  "mcpServers": {
    "devradar": {
      "command": "npx",
      "args": ["-y", "github:Verafyai/devradar"]
    }
  }
}

In Claude Code: claude mcp add devradar -- npx -y github:Verafyai/devradar

The server is one file with no dependencies. To run it without npx, download server.js and use node /path/to/server.js as the command.

devradar_scanScan a docs or website URL. Waits for the report by default and returns its summary and link.
devradar_reportRead a report by token or link: headline, every finding, and the competitors found.

Set DEVRADAR_URL to point the server at another deployment.

How it treats your site

  • Every request identifies itself as DevRadar/0.1.0, with a link back to this site.
  • It respects robots.txt and fetches only public pages.
  • Requests to a host are spaced at least 400 ms apart.
  • Each domain has one request budget per 24 hours, shared by everyone who scans it.
  • We never publish who failed a check.
