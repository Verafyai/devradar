How it works

Paste a URL. Get one report.

The scan reads only public pages, identifies itself, and respects robots.txt.

1. Paste your docs or website

No account. DevRadar finds your docs, API reference, GitHub and community links from there.

2. DevRadar reads it

It fetches pages as DevRadar/0.1.0, then as Chrome, ClaudeBot, GPTBot and curl to compare what each one gets. Requests are spaced out and every domain has a shared daily budget, so no site gets hammered.

3. It looks outward

It finds your competitors and runs their docs through the same checks, then gathers personas, events, communities, buzz on X, integrations and GitHub adoption.

4. You get the report

About 90 seconds, never more than 150. The report has an unlisted link you can share. Scanning the same domain again within 24 hours returns the same report.

Everything the scan checks is listed on the home page. The API and the MCP server are in the docs.
